# 49. Group Anagrams

**Difficulty:** Medium

## Задача

Дан массив строк.

Необходимо объединить строки, являющиеся анаграммами, в отдельные группы.

Анаграммы — это слова, состоящие из одинаковых символов, но расположенных в разном порядке.

Например:

`eat`

`tea`

`ate`

являются анаграммами.

## Идея решения

Если отсортировать символы в словах, являющихся анаграммами, получится одинаковая строка.

Например:

`eat -> aet`

`tea -> aet`

`ate -> aet`

Поэтому отсортированную версию слова можно использовать как ключ в `unordered_map`.

В качестве значения хранится массив исходных слов, соответствующих этому ключу.

## Алгоритм

1. Создать `unordered_map`.
2. Пройти по всем словам.
3. Для каждого слова создать копию.
4. Отсортировать символы этой копии.
5. Использовать отсортированную строку как ключ.
6. Добавить исходное слово в массив по этому ключу.
7. После обработки всех слов перенести группы из `unordered_map` в результирующий массив.
8. Вернуть результат.

## Сложность

Пусть:

- `n` — количество слов;
- `k` — средняя длина одного слова.

Сортировка одного слова занимает:

`O(k log k)`

Поэтому:

**Time Complexity:** `O(n * k log k)`

**Space Complexity:** `O(n * k)`

Дополнительная память используется для хранения групп слов и их отсортированных ключей.
