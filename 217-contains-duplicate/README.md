# 217. Contains Duplicate

**Difficulty:** Easy

## Задача

Необходимо определить, содержит ли массив хотя бы один повторяющийся элемент.

## Идея решения

Используется `unordered_set`.

Во время прохода по массиву сохраняем каждый уже встреченный элемент в множество.

Если очередной элемент уже находится в множестве, значит в массиве существует дубликат и можно вернуть `true`.

Если весь массив был пройден и повторений не найдено, возвращается `false`.

## Алгоритм

1. Создать пустой `unordered_set`.
2. Пройти по всем элементам массива.
3. Проверить, содержится ли текущий элемент в множестве.
4. Если содержится — вернуть `true`.
5. Иначе добавить его в множество.
6. После завершения цикла вернуть `false`.

## Сложность

**Time Complexity:** `O(n)`

Мы один раз проходим по массиву.

**Space Complexity:** `O(n)`

В худшем случае в `unordered_set` будут сохранены все элементы массива.
