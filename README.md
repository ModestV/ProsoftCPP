# ProsoftCPP

Репозиторий для школы разработчиков 2026-2027 ПрософтСистемы.

Репозиторий содержит решения задач LeetCode на языке C++.

Цель работы — изучение базовых алгоритмов, структур данных и синтаксиса C++.

## Решённые задачи

| № | Задача | Сложность | Основная идея |
|---|---|---|---|
| 217 | Contains Duplicate | Easy | Hash Set |
| 1 | Two Sum | Easy | Hash Map |
| 121 | Best Time to Buy and Sell Stock | Easy | One Pass |
| 3 | Longest Substring Without Repeating Characters | Medium | Sliding Window |
| 49 | Group Anagrams | Medium | Hash Map + Sorting |

Каждая папка содержит:
- `solution.cpp` — решение на C++;
- `README.md` — описание алгоритма и его сложности.
