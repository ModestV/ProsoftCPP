# 3. Longest Substring Without Repeating Characters

**Difficulty:** Medium

## Задача

Дана строка `s`.

Необходимо найти длину самой длинной подстроки, в которой все символы уникальны.

Например:

`abcabcbb`

Самая длинная подстрока без повторяющихся символов:

`abc`

Ответ:

`3`

## Идея решения

Используется техника `Sliding Window`.

Для текущего окна используются две границы:

- `left` — левая граница;
- `right` — правая граница.

Символы текущего окна хранятся в `unordered_set`.

Правая граница постепенно перемещается по строке.

Если текущий символ уже присутствует в окне, левая граница двигается вправо, а символы удаляются из множества до тех пор, пока повтор не исчезнет.

После этого текущий символ добавляется в окно, и обновляется максимальная длина.

## Алгоритм

1. Создать пустой `unordered_set`.
2. Установить `left = 0`.
3. Установить максимальную длину равной `0`.
4. Перемещать `right` по всей строке.
5. Если `s[right]` уже находится в множестве:
   - удалить символ `s[left]`;
   - увеличить `left`.
6. Добавить `s[right]` в множество.
7. Вычислить длину текущего окна:

   `right - left + 1`

8. Обновить максимальную длину.
9. Вернуть результат.

## Сложность

**Time Complexity:** `O(n)`

Каждый символ добавляется в окно и удаляется из него не более одного раза.

**Space Complexity:** `O(n)`

В худшем случае в `unordered_set` могут храниться все символы строки.
