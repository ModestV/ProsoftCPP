# 121. Best Time to Buy and Sell Stock

**Difficulty:** Easy

## Задача

Дан массив `prices`, где `prices[i]` — цена акции в день `i`.

Необходимо выбрать один день для покупки акции и один более поздний день для её продажи так, чтобы получить максимальную прибыль.

Если получить прибыль невозможно, нужно вернуть `0`.

## Идея решения

Во время прохода по массиву храним минимальную цену акции, которую уже встретили.

Для каждого дня считаем, какую прибыль можно получить, если купить акцию по минимальной цене из предыдущих дней, а продать сегодня.

Если текущая прибыль больше ранее найденной максимальной прибыли, обновляем результат.

## Алгоритм

1. Сохранить первую цену как минимальную.
2. Создать переменную для максимальной прибыли.
3. Пройти по оставшимся ценам.
4. Для каждого дня вычислить:

   `currentProfit = currentPrice - minPrice`

5. Обновить максимальную прибыль.
6. Если текущая цена меньше минимальной, обновить минимальную цену.
7. Вернуть максимальную прибыль.

## Сложность

**Time Complexity:** `O(n)`

Массив просматривается один раз.

**Space Complexity:** `O(1)`

Используется только несколько дополнительных переменных.
